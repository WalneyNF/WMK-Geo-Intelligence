2. Arquitetura do teste

Programa cliente → HTTP POST → Ponte 8770 → external-positions.jsonl
                                          ↓
                         GET /api/v1/external/positions

Simulador Python → Ponte 8766 → GET /api/v1/vehicles
                                         ↓
                                   quatro carros

As duas fontes são separadas. O POST não acrescenta automaticamente o quinto carro à resposta do simulador. Não confunda ingestão com visualização.

3. Preparar ambiente isolado

Abra PowerShell na pasta D:\Ferramentas\traccar\laboratorio-gps. Não desligue a porta 8766. Para reproduzir em outro momento, escolha uma porta livre e uma chave temporária própria:

cd D:\Ferramentas\traccar\laboratorio-gps
$env:WMK_BRIDGE_PORT = '8770'
$env:WMK_BRIDGE_WRITE_KEY = Read-Host 'Crie uma chave temporária'
py -3 wmk_bridge.py

A porta 8770 foi usada no teste. Se estiver ocupada, escolha outra. A chave deve permanecer privada; não a inclua no repositório.

4. Enviar posição fictícia em outro PowerShell

$chave = Read-Host 'Chave temporária da ponte'
$body = @{
  id = 'WMK-EXTERNO-001'
  latitude = -22.281
  longitude = -42.531
  simulated = $true
} | ConvertTo-Json
Invoke-RestMethod -Method Post `
  -Uri 'http://127.0.0.1:8770/api/v1/external/positions' `
  -Headers @{ 'X-WMK-API-Key' = $chave } `
  -ContentType 'application/json' -Body $body

Esperado: HTTP 202, accepted: true e record com ID, coordenadas e horário do servidor. Use somente posições fictícias ou autorizadas.

5. Consultar e comparar

Invoke-RestMethod 'http://127.0.0.1:8770/api/v1/external/positions'
Invoke-RestMethod 'http://127.0.0.1:8766/api/v1/vehicles?source=simulator'

O primeiro endpoint retorna eventos externos, o segundo retorna veículos normalizados do simulador. Os formatos JSON são diferentes. O cliente HTML didático espera schemaVersion: "1.0" e items de veículos, por isso não consome diretamente a resposta externa.

6. Testes negativos

Faça POST sem X-WMK-API-Key: esperado 401 se a chave estiver configurada. Faça POST com chave errada: esperado 401. Faça POST com latitude fora de −90 a 90: esperado 400. Com a escrita desabilitada no processo, o endpoint retorna 403. Esses códigos foram definidos no servidor de laboratório; não representam automaticamente o comportamento do WMK Geo Bridge independente.
